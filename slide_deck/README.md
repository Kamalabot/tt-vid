# The Studio Pitch Deck

This project contains a pitch deck for a design studio named "The Studio".

## Files

*   `the-studio-pitch-deck.html`: The main pitch deck file. Open this in a browser to view the presentation.
*   `brutalist-theme.css`: The theme file for the pitch deck.
*   `deck.md`: The markdown content for the pitch deck.
*   `index.html`: An alternative version of the pitch deck.
*   `mos0ux79-about_marp.md`: A file about Marp.

## How to view

Open the `the-studio-pitch-deck.html` file in a web browser.
