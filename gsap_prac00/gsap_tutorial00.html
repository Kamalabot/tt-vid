1. Core Tween Mechanics

gsap.to() — Animate to targeted values

Moves element properties from current state down to defined destinations.

gsap.to(".box-1", { x: 400, rotation: 360, duration: 1.5, ease: "power2.out" });

gsap.from() — Animate from initial state

Starts from the values inside the configuration object and animates down to native CSS values.

gsap.from(".box-2", { x: 400, opacity: 0, scale: 0.2, duration: 1.5 });

gsap.fromTo() — Explicit boundaries

Forces defined start values and runs down to exact end targets regardless of current state metrics.

gsap.fromTo(".box-3", { x: 0, opacity: 0.2 }, { x: 400, opacity: 1, rotation: -180, duration: 1.5 });

2. Sequencing & Timeline Controls

gsap.timeline() — Multi-step sequences

Chains animations chronologically without manual calculation chains.

let tl = gsap.timeline();
tl.to(".box-1", { x: 200, duration: 0.5 })
  .to(".box-2", { x: 200, rotation: 45, duration: 0.5 }, "+=0.2") // relative shift
  .to(".box-3", { x: 200, scale: 1.3, duration: 0.5 }, "<");     // align with start

Runtime Instance Controls

Interact with an ongoing timeline thread dynamically via memory handles.

3. Advanced Properties & Utility Arrays

Advanced Arrays: Stagger and Loop Utility

Spreads start intervals smoothly across all elements matching the selector block.

gsap.to(".box", { 
  x: 450, 
  stagger: 0.15, 
  repeat: 1, 
  yoyo: true, 
  ease: "back.out(1.7)" 
});
